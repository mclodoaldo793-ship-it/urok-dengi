# Урок «Деньги и их функции»

Интерактивная презентация для урока: бартер-квест, история денег, поиск фальшивки, «Музей неудачных денег»
про свойства денег, 5 функций денег, задание «Один день из жизни тысячи» и командная игра «Битва кофеен».
Ученики голосуют с телефонов.

- Сайт ведущего: https://mclodoaldo793-ship-it.github.io/urok-dengi/
- Страница для телефонов: https://mclodoaldo793-ship-it.github.io/urok-dengi/p.html (открывается по QR-коду с первого слайда)

## Как вести урок

1. Откройте сайт на компьютере, подключённом к проектору. Кнопка ⛶ или клавиша F включает полный экран.
2. На первом слайде есть QR-код. Ученики сканируют его и попадают в комнату урока (код из 5 букв).
3. Листайте стрелками → и ←. Когда на слайде есть вопрос, он сам появляется на телефонах, а голоса видны на экране.
4. Клавиша N показывает подсказки ведущему, Q — QR-код в любой момент.

Голоса идут через бесплатные публичные MQTT-серверы (EMQX и HiveMQ), без регистрации.
Если интернета нет, урок работает и без телефонов: отвечайте поднятием руки и кликайте ответ сами.

## Сборка

Исходники лежат в `src/`. После правок запустите:

```bash
bash build.sh
```

Скрипт соберёт `docs/index.html` (ведущий), `docs/p.html` (телефоны) и `urok-dengi.html`
(тот же урок одним файлом, открывается двойным кликом).

QR-коды рисует библиотека [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT).
